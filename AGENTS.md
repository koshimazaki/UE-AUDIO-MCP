# Agent instructions

This repository keeps one set of instructions for all coding agents:

- **Project instructions:** [`.claude/CLAUDE.md`](.claude/CLAUDE.md) covers the architecture, critical rules, file layout, key scripts and the UE breaking-changes checklist. Read it before changing anything.
- **Task guides:** [`.claude/skills/`](.claude/skills/) has one `SKILL.md` per area: MetaSounds DSP, Blueprint audio, Wwise setup, driving the UE5 plugin, plugin development and full-system builds.

Make changes in those files. This one only points to them, so it can't drift.
