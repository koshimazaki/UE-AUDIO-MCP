# Agent instructions

This repository keeps one set of instructions for all coding agents:

- **Project instructions:** [`.claude/CLAUDE.md`](.claude/CLAUDE.md) covers the architecture, layout, commands and conventions. Read it before changing anything.
- **Folder notes:** [`ue5_plugin/CLAUDE.md`](ue5_plugin/CLAUDE.md) (plugin build and the UE breaking-changes checklist) and [`scripts/CLAUDE.md`](scripts/CLAUDE.md) (maintenance scripts). Read the one for the folder you're working in.
- **Task guides:** [`.claude/skills/`](.claude/skills/) has one `SKILL.md` per area: MetaSounds DSP, Blueprint audio, Wwise setup, driving the UE5 plugin, plugin development and full-system builds. Some skills keep longer reference files next to their `SKILL.md`.

Make changes in those files. This one only points to them, so it can't drift.
